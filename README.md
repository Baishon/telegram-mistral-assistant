# Telegram AI для личного аккаунта

Проект подключается к вашему **личному Telegram-аккаунту** через Telethon. Когда вы отправляете сообщение, начинающееся с `/bot`, скрипт редактирует его на «Обдумываю…», передает запрос AI-провайдеру и заменяет текст на ответ.

Пример:

```text
/bot Объясни, что такое Python в двух предложениях
```

## Настройка

1. Установите Python 3.10 или новее.
2. Создайте Telegram API-приложение на [my.telegram.org](https://my.telegram.org) и получите `api_id` и `api_hash`.
3. Скопируйте `.env.example` в `.env` и заполните:
   - `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` — учетные данные приложения для входа личного аккаунта;
   - `MISTRAL_API_KEY` — API-ключ Mistral;
   - `MISTRAL_AGENT_ID` — ID агента Mistral (значение вида `ag_...`);
   - `MISTRAL_AGENT_VERSION` — необязательно, версия агента, по умолчанию `0`.
4. Установите зависимости:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

5. Один раз выполните вход в личный аккаунт:

   ```powershell
   python login.py
   ```

   Введите номер телефона, код подтверждения из Telegram и, если включена, пароль двухэтапной аутентификации. Файл сессии появится по пути `data/user_session.session`. Это секрет, который дает доступ к аккаунту: не передавайте и не публикуйте его.

6. Запустите обработчик команд:

   ```powershell
   python main.py
   ```

## Где задавать токены

Настройки находятся в корневом файле `.env` рядом с `main.py`:

- `MISTRAL_API_KEY` — секретный ключ API Mistral.
- `MISTRAL_AGENT_ID` — ID агента Mistral, не API-ключ.
- `MISTRAL_AGENT_VERSION` — версия агента, по умолчанию `0`.
- `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` — вход **личного аккаунта**, берутся на `my.telegram.org`.
- `BOT_TOKEN` — необязательный токен отдельного Telegram-бота, который выдает `@BotFather`. Текущая команда работает от личного аккаунта через Telegram API и этот токен не использует. Токен бота сам по себе не дает войти в личный аккаунт.

Не добавляйте `.env` или файл сессии в Git и не отправляйте их другим людям.

## Ограничения

- Обрабатываются исходящие сообщения личного аккаунта, текст которых начинается с `/bot`.
- Каждый запрос передается указанному агенту Mistral отдельным вызовом.
- Ответ длиннее лимита Telegram (4096 символов) обрезается.
- Скрипт должен быть запущен, чтобы обрабатывать команды.
